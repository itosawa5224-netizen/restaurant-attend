# ☕️飲食店向けアテンド業務支援システム　<br>ー Restaurant-Attendant Support System ー


飲食店の繁忙時における、「来店客受付〜客席へのご案内」までの【アテンド業務】を補助する従業員向けシステムです。



## 📖 概要

 ・ターゲット：飲食店の繁盛店で働くフロアリーダー・ホールスタッフ<br>
 
<!--入店待ちのお客様の人数構成や店の空席状況を把握し、空いたお席へ迅速にご案内する【アテンド業務】において、必要な情報を一元化しスタッフ全体に共有するシステム。<br>
また、”待機人数を記憶する”、 ”空席状況をリアルタイムで把握する”、 ”どの席に案内するのが最適か判断する” といった業務を支援する。-->

### 背景

 　繁盛する飲食店では、土日祝日のランチタイムや大型連休・年末年始などに来店客が集中し、店の外まで行列を作ります。<br>
 　ホールスタッフとして従事していた実際のアルバイト経験をもとに、お客様の案内（アテンド）業務を担う際の業務分析を行い、以下のような<課題>を抽出しました。<br>
 
 <課題>
- 紙の受付表(ウェイティングボード)による管理の煩雑さ
- フロアリーダーへの業務集中と属人化
- 待機客の人数構成と空席状況の把握・座席決定の判断にかかる負担
- 口頭による指示や情報共有の不確実性
- 不確実な情報共有によるタイムロス


### 目的

システムにより上記の課題を解決し、

- それまで属人化していた繁忙時の業務負担を分散させる
- 業務中の「認知負荷」を軽減させる
- スタッフ間での情報共有を確実なものにする

以上を目的に開発に臨みました。



## ✨ 実装機能　

- **機能1: 受付登録・一覧表示**	--- 来店客の名前・人数構成などを登録し、待機順を一覧表示する
- **機能2: テーブル状態更新**	--- スタッフの操作により、各テーブルの利用状態を更新する
- **機能3: フロア管理**   --- 随時更新されるフロア状況をリアルタイムで共有する
- **機能4: 案内候補提示**	--- 来店人数・構成などに応じて案内する席の候補を優先度順に提示する
- **機能5: バッシング優先順位表示**	--- バッシング(テーブル片付け)が必要な席を優先度順に表示する
