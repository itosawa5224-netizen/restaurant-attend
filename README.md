飲食店におけるお客様の順番待ち予約〜席へのご案内までの「アテンド業務」を補助するための、従業員向けアプリケーションに関するポートフォリオです。

![デモのスクリーンショットやGIF](docs/images/demo.gif)

## 📖 概要

このプロジェクトは、飲食系の繁盛店で働くホールスタッフによる使用を想定し、アテンド業務を効率化・非属人化することで店舗全体の接客力やホスピタリティ向上へ繋げるために開発しました。


### なぜ作ったのか（モチベーション）

- 大学生時代に従事した飲食店でのアルバイトで、ホール業務の一環としてアテンド業務やスタッフへの指示出しを行っていた。
- □□を実現するツールが存在しなかった
- ××の技術を実践的に学びたかった
